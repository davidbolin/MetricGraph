# Summary Method for `graph_lme` Objects

Function providing a summary of results related to metric graph mixed
effects regression models.

## Usage

``` r
# S3 method for class 'graph_lme'
summary(object, all_times = FALSE, ...)
```

## Arguments

- object:

  an object of class `graph_lme` containing results from the fitted
  model.

- all_times:

  Show all computed times.

- ...:

  not used.

## Value

An object of class `summary_graph_lme` containing information about a
*graph_lme* object.

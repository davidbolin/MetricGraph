# Convert a `psp` object to a metric graph object

This function converts a `psp` object (from the `spatstat` package) into
a metric graph object.

## Usage

``` r
psp.to.graph(psp.object)
```

## Arguments

- psp.object:

  A `psp` object to be converted.

## Value

A metric graph object with edges defined by the segments in the `psp`
object.
